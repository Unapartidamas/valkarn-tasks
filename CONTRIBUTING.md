# Contributing to Valkarn Tasks

Thank you for considering a contribution to Valkarn Tasks!

---

## Before You Start

All contributions require agreeing to our [Contributor License Agreement (CLA)](CLA.md).
By opening a pull request you confirm you have read and accepted its terms.

This allows Us to maintain the dual-license model that keeps Valkarn Tasks free for
individuals and small studios while sustaining ongoing development.

---

## How to Contribute

1. **Open an issue first** for significant changes — discuss the approach before writing code.
2. **Fork** the repository and create a branch from `master`.
3. **Write clear, focused commits** — one logical change per commit.
4. **Test your changes** — run the test suite in `_TestRunner~/` before submitting.
5. **Open a pull request** with a clear description of what and why.

---

## Code Style

- Follow the existing conventions in the file you are editing.
- No unnecessary comments — code should be self-explanatory.
- Keep allocations in mind — this is a zero-allocation library on the hot path.

---

## Reporting Bugs

Open an issue on GitHub with:
- Unity version
- Reproduction steps
- Expected vs actual behavior
