# 许可证

## 免费许可证

**个人**及**年总收入低于 1,000,000 美元的组织**可免费使用。

您可以在项目中免费使用、复制、修改和分发 Valkarn Tasks，
但须在软件的所有副本或实质性部分中包含版权声明。

## 商业许可证

**年总收入达到或超过 1,000,000 美元的组织**必须获得商业许可证。

**€2,999 / 年** — 涵盖在 12 个月许可期内公开发布的所有游戏和产品。

[购买商业许可证 →](https://tasks.valkarn.com/licensing)
