# 安装

## 系统要求

- **Unity 2023.1** 或更高版本
- **.NET Standard 2.1**

可选包（解锁额外功能）：

| 包 | 版本 | 功能 |
|---------|---------|---------|
| `com.unity.entities` | 1.0+ | ECS 异步系统 |
| `com.unity.burst` | 1.8+ | Burst 调度器 |
| `com.unity.collections` | 2.0+ | NativeTimerHeap |
