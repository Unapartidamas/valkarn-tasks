# ライセンス

## 無料ライセンス

**個人**および**年間総収益が1,000,000 USD未満の組織**は無料で利用できます。

ソフトウェアのすべてのコピーまたは実質的な部分に著作権表示を含める限り、
Valkarn Tasks をプロジェクトで無償で使用、複製、改変、配布することができます。

## 商用ライセンス

**年間総収益が1,000,000 USD以上の組織**は商用ライセンスを取得する必要があります。

**$199 / 年** — 12ヶ月のライセンス期間中に公開リリースされたすべてのゲームおよび製品を対象とします。

[商用ライセンスを購入する →](https://tasks.valkarn.com/licensing)
