# インストール

## 必要要件

- **Unity 2023.1** 以降
- **.NET Standard 2.1**

オプションパッケージ（追加機能を有効化）：

| パッケージ | バージョン | 機能 |
|---------|---------|---------|
| `com.unity.entities` | 1.0以降 | ECS非同期システム |
| `com.unity.burst` | 1.8以降 | Burstスケジューラー |
| `com.unity.collections` | 2.0以降 | NativeTimerHeap |
