# Установка

## Требования

- **Unity 2023.1** или новее
- **.NET Standard 2.1**

Дополнительные пакеты (открывают дополнительные возможности):

| Пакет | Версия | Возможность |
|-------|--------|-------------|
| `com.unity.entities` | 1.0+ | Асинхронные ECS-системы |
| `com.unity.burst` | 1.8+ | Планировщик Burst |
| `com.unity.collections` | 2.0+ | NativeTimerHeap |
