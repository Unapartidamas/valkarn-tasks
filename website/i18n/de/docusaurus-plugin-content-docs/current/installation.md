# Installation

## Voraussetzungen

- **Unity 2023.1** oder neuer
- **.NET Standard 2.1**

Optionale Pakete (schalten zusätzliche Funktionen frei):

| Paket | Version | Funktion |
|-------|---------|---------|
| `com.unity.entities` | 1.0+ | Asynchrone ECS-Systeme |
| `com.unity.burst` | 1.8+ | Burst-Scheduler |
| `com.unity.collections` | 2.0+ | NativeTimerHeap |
